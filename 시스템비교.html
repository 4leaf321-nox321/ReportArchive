ReportArchive vs Obsidian vs Notion vs Confluence

2026년 5월 기준. 보고서 작성에 특화된 ReportArchive 의 강점이 보이도록 다섯 영역(시각화 · 협업 · 데이터 통제 · RAG · AI 자동작성)을 중심으로 비교.

1. 한 줄 정체성 2. 핵심 5영역 비교표 3. 세부 기능 매트릭스 4. ReportArchive 강점 카드 5. 사용 사례별 추천
📌 업데이트 포인트 — ReportArchive 는 이전 비교 시점 이후 인라인 협업 (스레드형 코멘트 + 해결 상태 + 인박스 + 편집자/활동/알림 시스템) 과 도메인 컨텍스트 자동 주입형 AI 프롬프트 시스템({{widget_catalog}}, {{template_blocks}}, {{section_taxonomy}})을 추가했고, 종합보고(composite_reports) · 폴더/마운트 · 엔티티 마스터데이터 · 위젯 31종 + 통합 annotation 레이어까지 갖췄음. 협업 약점이 크게 좁혀진 상태로 표를 재작성함.

1. 한 줄 정체성

네 제품은 카테고리는 비슷해도 겨냥하는 시장이 다름.

ReportArchive
시각화·도메인 위젯·AI 자동작성으로 무장한 보고서 작성 특화 플랫폼. 자체 호스팅 · 폐쇄망 친화.
위젯 31종 + Annotation
Obsidian
로컬 마크다운 파일 기반의 개인 PKM/노트 그래프. 플러그인 생태계로 확장.
Local-first · Markdown
Notion
노트 · DB · 위키 · 프로젝트를 한 도구에 담는 All-in-one 워크스페이스.
DB view 패러다임
Confluence
엔터프라이즈 팀 위키 + Atlassian 생태계. Jira·Bitbucket 연동.
엔터프라이즈 권한

4. ReportArchive 가 가장 잘 하는 것 (강점 카드)

5개 영역에서의 결정적 차별점.

📊 시각화 — 단연 1위

위젯 31종 + 통합 annotation 레이어. 단순 차트만이 아니라 도메인 위젯(equation/raci/quadrant/milestone/comparison/network)까지 포함.

  • 좌표 차트 7 (chart · scatter · radar · box · density · heatmap · contour)
  • 비율 4 (pie · waffle · treemap · packing)
  • 흐름/관계 5 (flowchart · tree · mind_map · sankey · network)
  • 주석은 vline/range/point/rect/arrow/text · 3가지 좌표공간 공통 적용
Notion ~2 · Confluence ~5+marketplace · Obsidian 플러그인 의존

🤖 AI 자동작성 — 위젯 단위로

다른 도구의 AI는 "텍스트"를 쓰지만 ReportArchive 는 위젯 JSON 을 직접 생성. 스키마 검증으로 형식 오류가 차단됨.

  • {{widget_catalog}} · {{widget_examples}} 자동 주입
  • {{template_blocks}} 로 현재 페이지 patch-style 편집
  • 프롬프트 카탈로그 — 승급(promote) · 공유 권한 모델
Notion AI는 텍스트, Confluence는 도입 초기, Obsidian은 플러그인

🗣️ 협업 — 격차 빠르게 좁힘

스레드형 코멘트 + 해결 상태 + 인박스 + 편집자 트래킹 + 활동 로그 + 알림. Notion 의 매끄러움엔 못 미치지만 보고서 단위 협업에 필요한 모든 1차원 충족.

  • 편집 락 — 동시 편집 충돌 방지 (lock-based)
  • 받은 코멘트 인박스(/personal/inbox) — 내 보고서의 미해결 스레드 집계
  • 활동 타임라인 — 변경 이력 추적
Obsidian은 본질적으로 단일 사용자 → 압도

🔒 데이터 통제 — 최상위

완전 자체 호스팅. apptainer SIF 단일 번들 + Postgres host + 폐쇄망 배포 1차 시민. 외부 LLM 호출 없이도 본문 기능 100% 동작.

  • 데이터·업로드·로그 모두 자체 서버
  • SaaS 인 Notion 과 비교 불가 — 보안 민감 조직의 유일한 선택지
  • Confluence DC 와 동급, 추가 라이선스 비용 0
데이터 통제만 보면 Obsidian(로컬)도 강하지만 협업 불가

🧠 RAG-like 컨텍스트 주입

벡터 DB 없이도 도메인 컨텍스트를 토큰으로 자동 주입. 보고서 작성에서 자주 필요한 "어떤 위젯이 있나" · "이 보고서는 어떤 설비를 다루나" 같은 정보를 LLM 입력에 자동 첨부.

  • 위젯 카탈로그 + 예시 자동 주입
  • 섹션 분류(taxonomy)로 표준 항목 강제
  • 보고서↔entity 연결로 마스터데이터 자동 첨부
진짜 vector RAG가 필요하면 entity/prompt 모듈 확장점 명확

📑 보고서 작성 UX

PPT 슬라이드 가이드 · auto-fit / square cell · fullscreen viewer · RGL 드래그. 발표/인쇄/PPT 변환을 전제로 한 레이아웃 도구.

  • 위젯 props 와 content 가 분리 — 템플릿 재사용
  • 종합보고(composite) — 여러 보고서를 묶어 발표용 한 권으로
  • 위젯 컨텐츠 모델 일관성 — AI/사람 모두 같은 모델로 작업
Notion/Confluence 는 "위에서 아래로 흐르는 페이지" 모델
