> ⚠️ **아래 원안 대비 정정 3건**(실제 코드 기준):
> 1. **`accent` 는 접두사 없는 토큰** — `"teal"` 이지 `"rt-c-teal"` 이 아니다(§1 예시가 틀렸음).
>    백엔드 `_COLOR_TOKENS` enum 도 bare 토큰. AI 가 클래스명으로 주면 접두사만 벗겨 살린다.
> 2. **Tailwind safelist 불필요**(§5) — `rt-c-*`/`rt-bg-*`/`rt-hl-*` 는 `index.css` 최상위 플레인
>    규칙(@layer 밖)이라 purge 대상이 아니다. 카드가 쓸 색 배관(`rt-bg-*` 16% 틴트·`bandBgHex`
>    솔리드+자동대비·`highlightHex` export 틴트·`ColorSwatchPicker`)은 **전부 이미 있었다** —
>    신규 색 인프라 0. 새 *토큰*을 추가할 때만 3파일(tokens.js·index.css 라이트/다크·registry.py) 동시 수정.
> 3. **§5 에 PPTX 가 빠져 있었다.** PPTX 는 옵트인(`NATIVE_TEXT_TYPES`/`NATIVE_TABLE_TYPES`)이고
>    미등록 위젯은 **이미지로 캡처**된다. DOCX 는 더해서 미등록 시 `[지원하지 않는 위젯: card]`
>    문구를 문서에 찍는다 — 둘 다 필수 배선.
>
> 원안에 없던 배선 지점(신규 위젯 공통): 삽입 메뉴 `WidgetPicker.jsx`, 기본 크기 `widgetBuilder.js`,
> AI 레이아웃 `ai_authoring.py::_LAYOUT_SPEC`, 서식 복사 `widgetFormat.js`, auto-fit 기본
> **`reportLayout.js` + `ReportDetailPage.jsx` 두 곳**(동기화 필수).

> **목적:** PPT/인포그래픽식 보고서를 쓸 수 있게 하는 최소 핵심 블록. 배경·테두리·컬러 악센트 +
> (선택)아이콘 + 제목 + 본문을 담는다. **KPI 타일·콜아웃 밴드·개념 타일은 이 카드의 변형(variant)**
> 으로 파생 → 위젯 하나로 표현 폭 대부분을 커버. 그리드는 기존 레이아웃으로 나란히 배치(카드가
> 자식 위젯을 담는 컨테이너는 **후속**).

## 1. 콘텐츠 스키마 (widget-v1, `content`)
```jsonc
{
  "variant": "soft",              // soft(연한 배경) | outline(테두리) | filled(진한 배경) | banner(가로 강조 띠)
  "accent": "teal",               // 색 토큰 — **접두사 없음**(hex·rt-c-* 금지). 렌더 시 rt-c-/rt-bg- 를 붙인다
  "icon": "network",              // (선택) 아이콘 이름. 허용 셋 밖이면 무시+경고
  "eyebrow": "①",                 // (선택) 상단 소라벨/번호
  "title": "연결 탐색",
  "body": { "items": [{ "depth": 0, "text": "관련 시험·문서·공급사 즉시 연계" }] },
  "badge": { "text": "완료", "tone": "success" },   // (선택) success|info|warn|neutral
  "stat":  { "value": "OO", "unit": "건" },          // (선택) 있으면 KPI 타일로 렌더
  "footnote": "…"                 // (선택)
}
```
- `body`는 **RichText 콘텐츠 형식 재사용**(문자열/배열/`{items}` 모두 허용 → 렌더러·정규화 공유).
- `caption`/`caption_position`은 위젯 공통 규약 그대로(`captionPositionOf`).

## 2. Props (템플릿 블록 기본값, 대부분 content 주도)
`{ default_variant, default_accent, icon_enabled, allow_stat }` — 없으면 soft/`slate`/true.

## 3. 변형 = 파생 위젯 (별도 타입 불필요)
| 표현 | 설정 |
|---|---|
| 개념/아이콘 타일 | `icon` + `title` + `body` |
| KPI/지표 타일 | `stat{value,unit}` + `title`(=라벨) |
| 콜아웃/섹션 밴드 | `variant:"banner"` + `accent` + `title` |
| 상태 카드 | `badge{text,tone}` |

## 4. AI 느슨 입력 → 정규화 (`ai_authoring.py`)
`_PASSTHROUGH`/`_normalize_passthrough` 방식 재사용. 별칭 매핑:
`"문자열"`→`{title}` · `heading/label→title` · `text/desc/content→body` · `color→accent`(hex→근접 토큰 or 경고) ·
`badge:"완료"`→`{text:"완료",tone:추정}` · `icon` 허용셋 검증 · `stat`은 `{value,unit}`/`"OO건"` 파싱.
못 맞춘 키는 통과 대신 `warnings`.

## 6. 범위
- **MVP:** 단일 카드(variant 4종 + icon/stat/badge). 그리드는 기존 grid 레이아웃으로 나란히.
