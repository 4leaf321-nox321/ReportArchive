# 카드(Card) 위젯 설계 — 한 장 요약

> **목적:** PPT/인포그래픽식 보고서를 쓸 수 있게 하는 최소 핵심 블록. 배경·테두리·컬러 악센트 +
> (선택)아이콘 + 제목 + 본문을 담는다. **KPI 타일·콜아웃 밴드·개념 타일은 이 카드의 변형(variant)**
> 으로 파생 → 위젯 하나로 표현 폭 대부분을 커버. 그리드는 기존 레이아웃으로 나란히 배치(카드가
> 자식 위젯을 담는 컨테이너는 **후속**).

## 1. 콘텐츠 스키마 (widget-v1, `content`)
```jsonc
{
  "variant": "soft",              // soft(연한 배경) | outline(테두리) | filled(진한 배경) | banner(가로 강조 띠)
  "accent": "rt-c-teal",          // 색상 토큰(hex 금지 — 다크모드 대응). rt-c-* 재사용
  "icon": "network",              // (선택) 아이콘 이름. 허용 셋 밖이면 무시+경고
  "eyebrow": "①",                 // (선택) 상단 소라벨/번호
  "title": "연결 탐색",
  "body": { "items": [{ "depth": 0, "text": "관련 시험·문서·공급사 즉시 연계" }] },
  "badge": { "text": "완료", "tone": "success" },   // (선택) success|info|warn|neutral
  "stat":  { "value": "OO", "unit": "건" },          // (선택) 있으면 KPI 타일로 렌더
  "footnote": "…"                 // (선택)
}
```
- `body`는 **RichText 콘텐츠 형식 재사용**(문자열/배열/`{items}` 모두 허용 → 렌더러·정규화 공유).
- `caption`/`caption_position`은 위젯 공통 규약 그대로(`captionPositionOf`).

## 2. Props (템플릿 블록 기본값, 대부분 content 주도)
`{ default_variant, default_accent, icon_enabled, allow_stat }` — 없으면 soft/rt-c-slate/true.

## 3. 변형 = 파생 위젯 (별도 타입 불필요)
| 표현 | 설정 |
|---|---|
| 개념/아이콘 타일 | `icon` + `title` + `body` |
| KPI/지표 타일 | `stat{value,unit}` + `title`(=라벨) |
| 콜아웃/섹션 밴드 | `variant:"banner"` + `accent` + `title` |
| 상태 카드 | `badge{text,tone}` |

## 4. AI 느슨 입력 → 정규화 (`ai_authoring.py`)
`_PASSTHROUGH`/`_normalize_passthrough` 방식 재사용. 별칭 매핑:
`"문자열"`→`{title}` · `heading/label→title` · `text/desc/content→body` · `color→accent`(hex→근접 토큰 or 경고) ·
`badge:"완료"`→`{text:"완료",tone:추정}` · `icon` 허용셋 검증 · `stat`은 `{value,unit}`/`"OO건"` 파싱.
못 맞춘 키는 통과 대신 `warnings`.

## 5. 등록 체크리스트 (신규 위젯 공통 함정 포함)
- [ ] **backend `widgets/registry.py`** — 타입 스키마 + `default_props` + `content_schema_for`.
- [ ] **`REF_CATEGORY_BY_TYPE`에 반드시 추가** — 미분류 시 import 실패. 카드는 그림/표 번호 대상이 아니므로 **비번호(none) 카테고리**로.
- [ ] **`authoring_rules.json`** — content 형식·필수키·자주 틀리는 형식·예시(= MCP `describe_widgets` 단일 소스).
- [ ] **프론트 `widgets/Card.jsx` + 에디터** — 렌더러(variant별) + 인라인 편집(title/body/아이콘 피커/토큰 색상 피커/badge/stat). `_shared.jsx` 재사용.
- [ ] **색상 = `rt-c-*` 토큰** — 백엔드 스키마 enum + Tailwind purge safelist(토큰 클래스 동적 생성 함정).
- [ ] **아이콘** — 프론트 아이콘 라이브러리(lucide 등)에서 **큐레이션된 허용 셋**만 노출(임의 이름 금지).
- [ ] **`ai_authoring.py`** 정규화 + 단위테스트(느슨 입력 → 검증 통과).
- [ ] **MCP** — `describe_widgets(["card"])`로 룰 노출(추가 코드 0, 단일 소스).
- [ ] **HTML export** — 순수 DOM/CSS라 자산 인라인 불필요(이미지 아이콘이면 인라인 경로 확인).
- [ ] **caption_position** 지원.

## 6. 범위
- **MVP:** 단일 카드(variant 4종 + icon/stat/badge). 그리드는 기존 grid 레이아웃으로 나란히.
- **후속:** ⓐ **컨테이너 카드**(자식 위젯 블록을 담는 패널) — 레이아웃/중첩 모델 필요(대형), ⓑ 카드 그리드 프리셋(N열 자동), ⓒ 스텝 플로우/타임라인 강화(별도 위젯), ⓓ 프리셋 테마(카드 세트 색 일괄).

## 7. 검증
- 백엔드: `test_widgets_card`(스키마 검증·정규화·REF 등록), `describe_widgets` 응답에 card 룰 포함.
- 프론트: eslint + esbuild, variant/stat/badge 렌더 스냅샷.
- E2E: MCP `create_report_draft`에 `extra_blocks:[{type:"card",…}]`로 카드 생성 → 검증 통과.
