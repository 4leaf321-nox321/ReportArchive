# 카드(Card) 위젯 설계 — 한 장 요약

> **⚠️ 구조 변경(2026-07-19): 위젯 하나가 카드 여러 장을 담는다.**
> 원안·초기 구현은 "위젯 1개 = 카드 1장"이었다. 타일 그리드를 만들려면 블록을 N 개
> 만들어야 했는데, 보고서 편집기의 삽입은 전폭이고 좌우 삽입은 12 → 6/6 → 6/3/3 으로
> 폭이 어긋나 **4/4/4 를 만들 방법이 아예 없었다**(블록 복제 기능도 없음). 게다가 색·
> 표현형을 장마다 다시 정해야 했다. → **content.cards[] + columns** 로 재설계.
> - `cards: [{icon,eyebrow,title,body,badge,stat,footnote, variant?,accent?}]`
> - `variant`/`accent` 는 **세트 공통**(content 최상위)에 한 번. 장별 덮어쓰기 선택.
> - `columns`(1~4) = 한 줄 장수. 없으면 장수에 맞춰 자동.
> - **하위호환**: `cards` 가 없으면 content 최상위를 카드 1 장으로 읽는다(`cardsOf`).
>   이미 저장된 보고서가 그 형태 — 이 폴백은 지우면 안 된다.
> - 블록 자체는 **전폭**(`_LAYOUT_SPEC["card"]=(12,20)`, widgetBuilder `{12,5}`).
> - 모델 규칙은 `widgets/cardModel.js` 한 벌 — 화면·PPTX·DOCX 가 공유.
>
> **상태: 구현 완료(2026-07-19).** MVP 범위(§6) 전부 + 아이콘·PPTX 네이티브까지 포함.
> 결정: D1 **PPTX 네이티브 도형**(이미지 캡처 아님) · D2 **아이콘 포함**(32종 허용셋) ·
> D3 **variant 4종 전부**. 구현물:
> - **백엔드** `widgets/registry.py` — `_card_content`+`CARD`, `_CARD_ICONS`(32)/`_CARD_VARIANTS`(4)/
>   `_CARD_BADGE_TONES`(4), `REF_CATEGORY_BY_TYPE["card"]=None`(비번호). 본문은 `_OUTLINE_ITEM_SCHEMA`
>   를 긴 글과 **공유**(모듈 상수로 추출).
> - **프론트** `widgets/Card.jsx`(격자 렌더 + 장 추가/삭제 + 인라인 편집, 본문은
>   `RichTextRowEditor` 재사용 — Enter=새 줄·Tab=깊이·Backspace=삭제) +
>   `widgets/cardModel.js`(content 해석 규칙) + `widgets/cardIcons.js`(허용셋 ↔ 백엔드와 쌍).
>   ⚠️ 열 수는 **인라인 style** 로 — `grid-cols-${n}` 은 Tailwind 가 purge 한다.
> - **내보내기(둘 다 네이티브)** — DOCX `convertCard`(문단 shading, Word 에서 글자 편집·검색 가능),
>   PPTX `exportPptxCard.js`(fill+테두리 텍스트박스 = 카드 몸통, 배지=알약 도형, 아이콘만 SVG→PNG).
>   HTML/PDF 는 DOM 기반이라 추가 작업 0.
> - **AI 저작** `ai_authoring.py::_normalize_card` + `authoring_rules.json`(MCP `describe_widgets` 자동 노출).
> - **테스트** `tests/test_widgets_card.py` 23건(스키마·하위호환·enum·아이콘 허용셋·
>   세트공통 vs 장별·리스트→N장·AI 느슨입력 정규화).
>
> ⚠️ **아래 원안 대비 정정 3건**(실제 코드 기준):
> 1. **`accent` 는 접두사 없는 토큰** — `"teal"` 이지 `"rt-c-teal"` 이 아니다(§1 예시가 틀렸음).
>    백엔드 `_COLOR_TOKENS` enum 도 bare 토큰. AI 가 클래스명으로 주면 접두사만 벗겨 살린다.
> 2. **Tailwind safelist 불필요**(§5) — `rt-c-*`/`rt-bg-*`/`rt-hl-*` 는 `index.css` 최상위 플레인
>    규칙(@layer 밖)이라 purge 대상이 아니다. 카드가 쓸 색 배관(`rt-bg-*` 16% 틴트·`bandBgHex`
>    솔리드+자동대비·`highlightHex` export 틴트·`ColorSwatchPicker`)은 **전부 이미 있었다** —
>    신규 색 인프라 0. 새 *토큰*을 추가할 때만 3파일(tokens.js·index.css 라이트/다크·registry.py) 동시 수정.
> 3. **§5 에 PPTX 가 빠져 있었다.** PPTX 는 옵트인(`NATIVE_TEXT_TYPES`/`NATIVE_TABLE_TYPES`)이고
>    미등록 위젯은 **이미지로 캡처**된다. DOCX 는 더해서 미등록 시 `[지원하지 않는 위젯: card]`
>    문구를 문서에 찍는다 — 둘 다 필수 배선.
>
> 원안에 없던 배선 지점(신규 위젯 공통): 삽입 메뉴 `WidgetPicker.jsx`, 기본 크기 `widgetBuilder.js`,
> AI 레이아웃 `ai_authoring.py::_LAYOUT_SPEC`, 서식 복사 `widgetFormat.js`, auto-fit 기본
> **`reportLayout.js` + `ReportDetailPage.jsx` 두 곳**(동기화 필수).

> **목적:** PPT/인포그래픽식 보고서를 쓸 수 있게 하는 최소 핵심 블록. 배경·테두리·컬러 악센트 +
> (선택)아이콘 + 제목 + 본문을 담는다. **KPI 타일·콜아웃 밴드·개념 타일은 이 카드의 변형(variant)**
> 으로 파생 → 위젯 하나로 표현 폭 대부분을 커버. 그리드는 기존 레이아웃으로 나란히 배치(카드가
> 자식 위젯을 담는 컨테이너는 **후속**).

## 1. 콘텐츠 스키마 (widget-v1, `content`)
```jsonc
{
  // ── 세트 공통 — 한 번만 정하면 모든 장에 적용 ──
  "variant": "soft",              // soft(연한 배경) | outline(테두리) | filled(진한 배경) | banner(가로 강조 띠)
  "accent": "teal",               // 색 토큰 — **접두사 없음**(hex·rt-c-* 금지). 렌더 시 rt-c-/rt-bg- 를 붙인다
  "columns": 3,                   // (선택) 한 줄에 몇 장(1~4). 없으면 장수에 맞춰 자동
  // ── 카드 목록 ──
  "cards": [
    {
      "icon": "network",          // (선택) 아이콘 이름. 허용 셋 밖이면 무시+경고
      "eyebrow": "①",             // (선택) 상단 소라벨/번호
      "title": "연결 탐색",
      "body": { "items": [{ "depth": 0, "text": "관련 시험·문서·공급사 즉시 연계" }] },
      "badge": { "text": "완료", "tone": "success" },   // (선택) success|info|warn|neutral
      "stat":  { "value": "OO", "unit": "건" },          // (선택) 있으면 KPI 타일로 렌더
      "footnote": "…",            // (선택)
      "variant": "filled",        // (선택) 이 장만 다르게 — 보통은 비워 세트 공통을 쓴다
      "accent": "purple"          // (선택) 위와 같음
    }
  ]
}
```
- `body`는 **RichText 콘텐츠 형식 재사용**(문자열/배열/`{items}` 모두 허용 → 렌더러·정규화 공유).
- `caption`/`caption_position`은 위젯 공통 규약 그대로(`captionPositionOf`). caption 은 격자 **바깥**
  머리글이고, 카드 안 제목은 `cards[].title` — 역할이 다르다.
- **하위호환**: `cards` 가 없으면 최상위의 `title`/`icon`/… 을 카드 1 장으로 읽는다(`cardModel.cardsOf`).

## 2. Props (템플릿 블록 기본값, 대부분 content 주도)
`{ default_variant, default_accent, icon_enabled, allow_stat }` — 없으면 soft/`slate`/true.

## 3. 변형 = 파생 위젯 (별도 타입 불필요)
| 표현 | 설정 |
|---|---|
| 개념/아이콘 타일 | `icon` + `title` + `body` |
| KPI/지표 타일 | `stat{value,unit}` + `title`(=라벨) |
| 콜아웃/섹션 밴드 | `variant:"banner"` + `accent` + `title` |
| 상태 카드 | `badge{text,tone}` |

## 4. AI 느슨 입력 → 정규화 (`ai_authoring.py`)
`_PASSTHROUGH`/`_normalize_passthrough` 방식 재사용. 별칭 매핑:
`"문자열"`→`{title}` · `heading/label→title` · `text/desc/content→body` · `color→accent`(hex→근접 토큰 or 경고) ·
`badge:"완료"`→`{text:"완료",tone:추정}` · `icon` 허용셋 검증 · `stat`은 `{value,unit}`/`"OO건"` 파싱.
못 맞춘 키는 통과 대신 `warnings`.

## 6. 범위
- **구현됨:** 카드 N 장 격자(variant 4종 + icon/stat/badge/eyebrow/footnote), 세트 공통 색·표현형 +
  장별 덮어쓰기, 열 수 조절(1~4), 장 추가·삭제, PPTX/DOCX 네이티브 내보내기, AI 저작(리스트→N장).
  ~~ⓑ 카드 그리드 프리셋~~ 은 이 구조가 대체 — 별도 프리셋이 필요 없다.
- **후속:** ⓐ **컨테이너 카드**(자식 위젯 블록을 담는 패널) — 레이아웃/중첩 모델 필요(대형),
  ⓒ 스텝 플로우/타임라인 강화(별도 위젯), ⓓ 프리셋 테마(여러 세트 색 일괄),
  ⓔ 카드 → 객체 링크(`entity_id`, 누르면 객체 프로필로).
