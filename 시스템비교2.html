ReportArchive vs Obsidian vs Notion vs Confluence — 냉정한 비교

편향 없이 — 각 도구의 진짜 강점과 정직한 약점. 별점은 동일 기준(★5 = 업계 1위급, ★1 = 사실상 부재).

관점: 이 페이지는 어느 한 도구를 강조하지 않는다. ReportArchive 가 이긴 영역에는 별 다섯을 주지만, 진 영역에는 별 한두 개만 준다. 시장 1위(Notion 의 협업, Confluence 의 엔터프라이즈, Obsidian 의 로컬-그래프)에는 그에 걸맞은 점수를 매겼다.

1. 정체성 — 같은 카테고리지만 다른 시장

기능 비교 전에 "원래 무엇을 위해 만들어졌는가" 부터 정리.

ReportArchive
시각화 위젯 + 도메인 특화 위젯 + AI 위젯 생성에 베팅한 보고서 작성 특화 플랫폼. 자체 호스팅.
신생 (사내·프로토타입)
Obsidian
로컬 마크다운 파일 기반의 개인 PKM/지식 그래프. 플러그인 1500+개의 모듈 시장.
로컬-우선 · 1.5+ Sync 유료
Notion
노트 · DB · 위키 · 프로젝트를 한 도구에 담는 All-in-one 워크스페이스. SaaS.
DB view + AI · 클라우드
Confluence
대규모 팀 위키 + Atlassian 생태계. 엔터프라이즈 표준. Cloud/DC 양쪽.
20년 검증 · marketplace

4. 도구별 솔직 강·약점

각 도구를 동등하게 다룸. 약점은 회피하지 않음.

ReportArchive 보고서 특화 · 자체 호스팅

강점

  • 위젯 31종 + 통합 annotation — 단일 도구에서 압도적
  • 도메인 위젯(equation/raci/quadrant/comparison/milestone)
  • AI 가 위젯 JSON 을 직접 생성 (스키마 검증)
  • 완전 자체 호스팅 · 폐쇄망 1차 시민
  • 발표/PPT 친화 레이아웃 · 종합보고(composites)
  • 라이선스 비용 0

약점

  • 실시간 동시 편집 X (lock 기반)
  • 멘션/실시간 알림 push 인프라 미완
  • 모바일 앱 없음 · 데스크탑 전용
  • 외부 임베드 카탈로그 사실상 없음(html_embed 하나)
  • 플러그인/마켓플레이스 0 (신생)
  • SSO/SAML/엔터프라이즈 audit 미흡
  • 모델·API 통합 탭 "준비 중" — 외부 SDK 연동 전제
  • 위키 계층/백링크/검색 모두 평균 이하
  • 운영 책임은 본인 (안정성·백업·업그레이드)
Obsidian 로컬-우선 PKM

강점

  • 로컬 마크다운 파일 — 데이터 통제 최강 · vendor lock-in 없음
  • 백링크 + 그래프뷰 — 지식 그래프 만들기 최적
  • 플러그인 1500+ — Dataview · Excalidraw · Canvas 등
  • 빠른 로컬 검색 · 정규식
  • 키보드 중심 · 마크다운 호환 · export 손실 없음
  • 개인 사용 무료

약점

  • 본질적으로 단일 사용자 — 협업 사실상 부재
  • Sync/Publish 모두 유료 (개인용)
  • 시각화 통합 X — 플러그인마다 스타일/스키마 따로
  • DB view / 구조화 데이터 부재
  • 학습곡선 — 일반 비개발자에게 어렵게 느껴짐
  • 모바일 편집 경험 데스크탑 대비 낮음
  • 플러그인 품질 편차 큼 · 보안 검증 본인 책임
Notion All-in-one 워크스페이스

강점

  • DB view 패러다임 — table/board/gallery/calendar/timeline
  • 실시간 협업 · 매끄러운 멘션 · 코멘트 — 업계 표준점
  • UI/UX 학습곡선 가장 낮음
  • 네이티브 임베드 30+ (Figma/Loom/Sheets)
  • 모바일 매끄러움
  • Notion AI — 텍스트 작성/요약/번역

약점

  • SaaS only — 자체 호스팅 불가 · 보안 민감 조직 부적합
  • 시각화/차트 사실상 부재
  • 도메인 특화 위젯 없음 (general purpose)
  • 엔터프라이즈 권한·audit 약함 (Confluence 대비)
  • export 시 layout 손실 · 재import 불가
  • 대용량 페이지에서 성능 저하
  • 장기 lock-in 위험 · 가격 인상 이력
Confluence 엔터프라이즈 위키

강점

  • Space 계층 + 권한 상속 + 페이지 history — 위키의 정석
  • SAML/SSO/감사/컴플라이언스 — 엔터프라이즈급
  • Atlassian 생태계 — Jira/Bitbucket 연동 1차 시민
  • Data Center 자체 호스팅 가능
  • marketplace 1000+ — 차트/Draw.io/Gliffy 등
  • 20년 운영 이력 · 대기업/정부 도입 사례

약점

  • UI 무겁고 구식 — 응답성 떨어짐
  • 기본 시각화/차트 빈약 — 좋은 건 모두 marketplace 유료
  • 실시간 동시편집 경험 Notion 대비 낮음
  • DB view 패러다임 없음 — 단순 table macro
  • 검색 품질·속도 대규모 space 에서 약점
  • 모바일 빈약
  • 라이선스 + marketplace 누적 비용 큼
  • 학습곡선 큼 · 일반 사용자 친화도 낮음
