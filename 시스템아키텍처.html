ReportArchive — 시스템 아키텍처

네 가지 관점에서 본 다이어그램. FastAPI 백엔드 + React/Vite 프론트엔드 + PostgreSQL, apptainer SIF로 묶어 systemd로 띄우는 단일 번들 배포 구조.

핵심 분리선

  • SIF 안: OS 베이스(ubuntu:24.04) · Python 3.12 · 백엔드 의존성 · 빌드된 프론트 dist
  • 호스트: apptainer · PostgreSQL · systemd · (선택) nginx
  • bind-mount: .env · uploads · logs — SIF 교체 시 살아남아야 하는 것들

02 런타임 / 요청 흐름

/api/* 요청 하나가 통과하는 레이어. 모든 응답은 표준 envelope { success, data, message, errors }.

sequenceDiagram
  autonumber
  participant U as 사용자
  participant S as React SPA
(shared/api/client.js)
  participant N as nginx
  participant F as FastAPI
(main.py)
  participant MW as CORS / 예외핸들러
(shared/errors.py)
  participant R as APIRouter
modules/<name>/routes.py
  participant A as 인증 의존성
(shared/auth.py)
  participant SVC as services.py
  participant ORM as SQLAlchemy
models.py
  participant DB as PostgreSQL

  U->>S: 페이지 / 액션 클릭
  S->>N: fetch /api/...
  N->>F: proxy_pass
  F->>MW: 미들웨어 통과
  MW->>R: route 매칭
  R->>A: get_current_user
  A-->>R: User
  R->>SVC: 도메인 함수 호출
  SVC->>ORM: 쿼리 / 커밋
  ORM->>DB: SQL
  DB-->>ORM: rows
  ORM-->>SVC: 객체
  SVC-->>R: 결과 (또는 도메인 에러 raise)
  R-->>F: Pydantic schema
  F-->>N: JSON envelope
  N-->>S: 응답
  S-->>U: 렌더 / 토스트

부가 경로

  • 정적 자산: 결합 배포일 때 /, /assets/*, SPA 폴백을 main.py가 직접 처리
  • 헬스체크: GET /api/health
  • OpenAPI: /api/docs, /api/redoc, /api/openapi.json

등록 지점

  • 마운트 prefix는 backend/app/modules/__init__.py 의 register_routers() 한 곳에 집중
  • 새 모듈 = app/modules/<name>/{routes,schemas,services,models}.py + register_routers()에 한 줄
