ReportArchive — 시스템 연결도 (v3)

화면(Frontend) → API(Backend) → 테이블(DB) 의 흐름을 도메인 단위로 끊어 보여주는 페이지. 도메인 8장 + 마지막에 전체 결선도 한 장.

1. 인증·사용자·워크스페이스 2. 보고서 작성/편집 3. 협업 · 알림 · 인박스 4. 종합보고 5. 템플릿 · 분류 메타 6. 엔티티 · 위젯 관계 7. AI 프롬프트 · VOC · 파일 8. 관리자 9. 전체 결선도
Frontend 모듈 Backend 모듈 (API) DB 테이블 파일시스템 / 외부 화살표 = 호출 / 소유
